# Continue from your existing save

The launcher keeps vanilla and mod saves in separate folders. You can copy your vanilla OpenGOAL saves into The Cinematic Legacy to keep playing.

1. Close the game.
2. On the vanilla game page in the launcher, open the cog beside **Advanced** and choose **Open Saves Folder**. Keep that folder open.

   ![Vanilla game cog menu with Open Saves Folder](https://raw.githubusercontent.com/JacopoBassan/the-cinematic-legacy-jak1/main/docs/media/vanilla-saves-menu.webp)

3. Select **Features → Mods** and open **The Cinematic Legacy** for the same game. Use its cog beside **Advanced** to choose **Open Saves Folder**.

   ![Mod cog menu with Open Saves Folder](https://raw.githubusercontent.com/JacopoBassan/the-cinematic-legacy-jak1/main/docs/media/cinematic-legacy-saves-menu.webp)

4. **Copy** the contents of the vanilla saves folder into the mod’s saves folder. Keep the originals. If the mod folder already has progress you want to keep, make a copy of it before replacing any files.
5. Start the mod and load your save.

If the mod’s **Open Saves Folder** option is missing, run the mod and create a save. Exit the game, return to the Mods list, then open the mod page again.

## From an earlier local install

A mod installed through the source has a separate save folder from a copy added with **Add from File**. Close the game, open **Open Saves Folder** on each mod’s page, and copy the old mod’s saves into the new mod’s folder. Keep the old install and original saves until you have loaded your progress in the new one.

These steps are for OpenGOAL saves. PCSX2 memory cards use a different format.
